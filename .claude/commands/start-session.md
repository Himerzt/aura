# /start-session

Dùng lệnh này ĐẦU MỖI PHIÊN LÀM VIỆC để nạp context đúng cách.

## Hướng dẫn cho Claude Code

1. Đọc `CLAUDE.md` — project overview, tech stack, rules
2. Đọc `docs/plan.md` — trạng thái hiện tại, phần nào đã xong
3. Tóm tắt lại bằng format sau:

---

**Dự án:** AURA — AI life coach với 4-agent pipeline

**Tech stack:** Next.js 15 + FastAPI + Gemini + JSON files + Docker + Nginx

**Tiến độ:**
- ✅ Phần [X]: [tên] — đã xong
- 🔄 Phần [Y]: [tên] — đang làm (nếu có)
- ⏳ Phần [Z]: [tên] — chưa bắt đầu

**Phần tiếp theo cần làm:** Phần [N] — [tên]

---

4. Hỏi: "Bạn muốn bắt đầu Phần [N] không, hay có câu hỏi gì trước?"
5. **Chưa làm gì cả** cho đến khi được xác nhận.
